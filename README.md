# AI 資料科學家全方位學程｜學習筆記與作業

我在修習「AI 資料科學家全方位學程」（線上錄播課 ＋ 直播專案實作）過程中，**用自己的話重寫**的章節筆記，以及九個專案作業的實作紀錄。持續更新中。

## ⚠️ 關於內容來源

- 本 repo **不包含**任何課程講義 PDF、投影片、講師提供的範例程式或資料集。
- 筆記是我聽課後自行整理的理解與速查，**不是課程教材的重製**；若內容與原課程說法有出入，以原課程為準。
- 專案作業的需求敘述由我自行改寫，解答程式由我自己撰寫。
- 若課程方認為任何內容不妥，請開 issue 告知，我會立即移除。
