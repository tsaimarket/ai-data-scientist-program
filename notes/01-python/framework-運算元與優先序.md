# 七類運算元 + 優先序速查

變數無需宣告，`=` 賦值後自動判型。多重賦值 `a, b = 1, 2`。一切皆**物件**（有 `id`/`type`/`value`，`id()` 回記憶體位址）。

## 1. 算術 Arithmetic

| 運算 | 符號 | 例 |
|---|---|---|
| 加減乘除 | `+ - * /` | `7/2 → 3.5`（永遠回 float） |
| 取餘 | `%` | `7 % 2 → 1` |
| 次方 | `**` | `2 ** 3 → 8` |
| 整除（向下取整） | `//` | `7 // 2 → 3` |

## 2. 比較 Comparison
`== != > < >= <=` → 回傳 `True/False`。

## 3. 賦值 Assignment（複合賦值）
`= += -= *= /= %= //= **= &= |= ^= >>= <<=`（`x += 3` 等同 `x = x + 3`）。

## 4. 邏輯 Logical
`and`（兩真才真）、`or`（一真即真）、`not`（反轉）。

## 5. 成員 Membership
`in` / `not in` —— 值是否在序列/容器中（`x in [1,2,3]`）。

## 6. 身分 Identity
`is` / `is not` —— 是否**同一個物件**（比 id，非比值）。注意 `==` 比值、`is` 比身分。

## 7. 位元 Bitwise

| 符號 | 名 | 例（x=10=0b1010, y=4=0b0100） |
|---|---|---|
| `&` | AND | `x & y = 0` |
| `\|` | OR | `x \| y = 14` |
| `^` | XOR | `x ^ y = 14` |
| `~` | NOT | 逐位元反轉 |
| `<<` | 左移補零 | `x << 2 = 40` |
| `>>` | 帶號右移 | `x >> 2 = 2` |

## 運算優先順序（高 → 低）

```
**                          次方
~x  +x  -x                  位元not、正負號
*  /  %  //                 乘除餘整除
+  -                        加減
<<  >>                      位元位移
&                           位元AND
^                           位元XOR
|                           位元OR
in not in is is not < <= > >= != ==   比較/成員/身分
not x                       邏輯NOT
and                         邏輯AND
or                          邏輯OR
```

口訣：**次方 > 算術 > 位移 > 位元 > 比較 > 邏輯**；不確定就加括號。
