# 離群值處理與資料轉換七類（M4）

> 定位：ETL 的 **T（Transform）下半場**。先決定「哪些資料不該留」，再決定「留下來的要怎麼改形狀」。

## 一、離群值（Outlier）

### 三種判準

| 判準 | 定義 | 工具 |
|---|---|---|
| **IQR 法** | 超出 `Q1 − 1.5×IQR` ～ `Q3 + 1.5×IQR` | 箱型圖的鬍鬚就是這條線 |
| **標準差法** | 超出 **平均值 ± 3 個標準差** | 假設近似常態才成立 |
| **Z-score** | `scipy.stats.zscore()` 算完取 `abs(z) > 3` 過濾 | ⭐ 一行完成，最快 |

```python
from scipy import stats
import numpy as np
df = df[(np.abs(stats.zscore(df[num_cols])) < 3).all(axis=1)]
```

### ⭐ 核心原則：找到離群值 ≠ 可以刪

**必須搭配領域專家討論「為什麼會有這個點」再決定怎麼處理。** 離群值有三種身分：

| 身分 | 例 | 處理 |
|---|---|---|
| **錄入錯誤** | 年齡 999 | 刪或修 |
| **真實極端值** | 雙11 當天營業額 | ⚠️ **不能刪**，刪了模型就看不到旺季 |
| **你要找的東西本身** | 盜刷、作弊帳號、套利下注 | ⭐ 這是**答案不是雜訊** |

🕳️ 失敗模式＝**無腦 3σ 濾一輪**，把真實存在的極端大戶、異常交易、極端賠率一起洗掉。異常偵測視角見 `framework-數據異常檢測抓作弊`、`principle-稀有事件是詐欺之母`。

## 二、資料轉換七類（ETL 的 T）

| # | 類型 | 在做什麼 |
|---|---|---|
| 1 | **去重複** Duplication | `drop_duplicates()`；先想清楚「重複」的鍵是什麼 |
| 2 | **格式修正** Format revision | 型別、日期格式、單位統一 |
| 3 | **鍵重整** Key restructuring | 換主鍵、建代理鍵，讓表能接起來 |
| 4 | **衍生** Derivation | ⭐ 算新欄位（比率、天數差）＝特徵工程的入口 |
| 5 | **過濾** Filtering | 只留需要的列／欄 |
| 6 | **合併** Joining | 多表接成一表 → 見下 |
| 7 | **切割** Splitting | 一欄拆多欄（地址拆縣市）、一表拆多表 |

## 三、Pandas 的優缺點（知道天花板在哪）

| ✅ 優點 | ❌ 缺點 |
|---|---|
| 語法直觀，學習曲線平 | **擴充性差** |
| CSV/Excel/JSON/XML/SQL 全支援 | ⭐ **所有資料需載入主記憶體** |
| 與 Matplotlib 無縫整合 | **不適合超大型資料集** |

⭐ **這條記憶體天花板就是「什麼時候該離開 Pandas」的判準**——資料大過 RAM 就該換 Dask／Spark／直接在資料庫端算（SQL 下推）。常見做法：大表在資料倉儲端算完，再把小結果拉回本機。

## 四、資料合併與重塑

| 函數 | 做什麼 | 重點 |
|---|---|---|
| **`merge()`** | 以**共同欄位**合併 | 支援 `how='inner'/'left'/'right'/'outer'`；⭐ 最常用，等同 SQL JOIN |
| **`join()`** | 以 **index 或 key** 為主合併 | 兩表 index 已對齊時最方便 |
| **`concat()`** | **堆疊** | `axis=0` 縱向（疊列）／`axis=1` 橫向（疊欄） |
| **`stack()` / `unstack()`** | **轉軸重塑** | 欄 ↔ 列互換；寬表 ↔ 長表 |

🕳️ **merge 後筆數變多＝多對多**——合併完第一件事永遠是 `len(df)` 對一下，別讓一對多默默把金額灌倍。
