# Matplotlib 速查（M11）

> 定位：M5 EDA 說「該看哪幾張圖」，**M11 說「那些圖怎麼畫出來」**。
> ⚠️ 選圖的**判準**不在這裡——那是 `framework-基本統計圖選型` 與 `principle-統計圖先保證正確再談直觀` 的事。本則只記操作。

## 一、兩個模組

| 模組 | 說明 |
|---|---|
| **pylab** | 介面近似 MATLAB |
| **pyplot** | 與 NumPy 整合，**實務上用這個** |

### pyplot 的呼叫順序（四步）

```
1. 創造一個 figure（畫布）
2. 在 figure 中創造一個 plotting area（繪圖區）
3. plot 一些 lines
4. 用 labels 裝飾 plot
```

## 二、Subplot：一張圖上放幾個子圖

**參數三個數字 ＝（列數, 行數, 序號）**

```python
from matplotlib import pyplot as pl
x = range(-8, 8)
y = [i**3 + 2*i**2 + i - 1 for i in x]
pl.subplot(211)   # 垂直 2 張、水平 1 張，畫第 1 張
```

| 寫法 | 意思 |
|---|---|
| `subplot(211)` | 2 列 1 行的第 **1** 張（上面那張） |
| `subplot(212)` | 2 列 1 行的第 **2** 張（下面那張） |
| `subplot(2,2,3)` | 2×2 的第 3 格（左下） |

⚠️ **序號從 1 開始**，不是 0——這是唯一會讓人一直畫錯格的地方。

## 三、格式字串（plot 的第三個參數）

`'ob--'` ＝ **藍色（b）＋ 圓點（o）＋ 虛線（--）**，三種屬性擠在一個字串裡。

| 類 | 常見值 |
|---|---|
| 顏色 | `b` 藍 `g` 綠 `r` 紅 `k` 黑 `w` 白 |
| 標記 | `o` 圓 `^` 三角 `s` 方 `.` 點 `*` 星 |
| 線型 | `-` 實線 `--` 虛線 `-.` 點劃 `:` 點線 |

配 `label=` 與 `legend()` 讓圖自己說明自己。

## 四、五種圖的繪製步驟（講義口徑）

| 圖 | 步驟重點 | ⚠️ 坑 |
|---|---|---|
| **Scatter 散點圖** | 隨機產生各 100 點；以**半徑 0.6 為分割線**，之外畫三角形、之內畫圓形；再繪出分隔線 | 要先**固定隨機種子**，否則重繪結果不一樣 |
| **Histogram 直方圖** | 產生常態分佈隨機變數（中心 x=0, y=5）；**bin 數目可自訂**（示範 10 與 20） | ⭐ **bin 數會改變你看到的形狀**——同一份資料換 bin 可以「看起來」雙峰或單峰 |
| **Bar Chart 長條圖** | N=5 條 bar；畫男女的平均值與標準差；定好 x 位置、寬 `width=0.35`、在男 bar 上疊女 bar、加標註 | 疊圖時 x 位置要自己算，否則會重疊 |
| **Pie Chart 圓餅圖** | 每片**逆時鐘依序**繪出；要標籤、要大小比例、用 `explode` 突出某片；用 `subplots()` 取得 ax 再畫 | 🔴 **軸線比例一樣才會圓**（`ax.axis('equal')`），否則畫出橢圓 |
| **Box Plot 盒鬚圖** | 作為資料分佈視覺化的補充 | 接 [framework-離群值與資料轉換](framework-離群值與資料轉換.md)：盒鬚圖外的點就是 IQR×1.5 抓到的那些 |

> 📌 兩個反覆出現的實作習慣：**①固定隨機種子以便重繪一致 ②所有圖都補 label 與 legend**。

## ⚠️ 這門課沒教、但本 vault 有更嚴的一層

講義只教「怎麼畫」，沒教「該畫哪個、畫了會不會誤導」。補上：

| 缺的那層 | 去哪讀 |
|---|---|
| 該用條形／餅／折線哪一個 | `framework-基本統計圖選型`（**條形＝數量／餅＝總分／折線＝序列** ＋ 三大誤用） |
| 條形圖 vs 直方圖到底差在哪 | `principle-條形圖與直方圖的區別`（⭐ 判準＝**能不能換順序**） |
| 餅圖的先天缺陷 | `framework-餅圖的三個缺陷` |
| 「版面清楚 ≠ 內容正確」 | ⭐ `principle-統計圖先保證正確再談直觀` |
| 單維圖怎麼長成多維 | `framework-統計圖延伸思路`（散點→氣泡、條形→堆積、餅→環形⚠️不超過兩層） |

## 對接

- **報酬率資料**：histogram 的 bin 數敏感度＝報酬分布厚尾的讀圖陷阱；box plot 接回撤分布。
